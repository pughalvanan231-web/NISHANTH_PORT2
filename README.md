# Orchestrated.nl Clone

An exact, pixel-accurate clone of **[https://orchestrated.nl/](https://orchestrated.nl/)** — the portfolio of Motion Director **Joris van Raaij**.

---

## Highlights & Features Replicated

1. **Brand & Typography**:
   - Original **Metro Sans** typeface (Regular & Medium `.woff2`) with pixel-tuned typography scale.
   - Exact vector SVG logotype of **Orchestrated** (`viewBox="0 0 276 40"`).
   - Authentic CSS variable system matching Orchestrated's frosted glass pills (`--glass-bg`, `--glass-outline`, backdrop blur).

2. **Interactive 3D WebGL Rocky Landscape (Hero)**:
   - Dynamic 3D undulating terrain with realistic mesh elevation and mouse parallax responsiveness.
   - Normal/color map texturing using `rocks_ground_02_col_2k.webp` and `lightMap_high.webp`.
   - Subtle atmospheric floating particle system and directional rim lighting.
   - "PLAY REEL" glass CTA button and animated scroll indicator wave.

3. **Generative Web Audio Engine & Sound Studio**:
   - Web Audio API generative ambient synthesizer with procedural chord progression and filtered pink noise atmospheric "air".
   - Sound toggle button with keyboard shortcut (`M` key) to globally mute/unmute.
   - Interactive Sound Studio modal allowing granular channel solo/mute for Bass, Chords, Melody, Drums, Lamp, Air, and Particles.
   - Tactile UI audio feedback (hover micro-tones, modal sound triggers).

4. **Impactful Collaborations**:
   - Infinite smooth dual-direction marquee tickers.
   - **Awards**: Awwwards, FWA, CSS Design Awards, The Webby Awards, The Lovie Awards (original SVGs).
   - **Clients**: BMW, Vast, Nike, Lucid, Moncler, Gucci, Koenigsegg, Porsche, Coach, Fortnite, Getty (original SVGs).

5. **Featured Cases & Interactive Work Grid**:
   - **Vast Motion Toolkit** (`Vast × Antinomy Studio`)
   - **Extra.Email** (`Extra.Email`)
   - **Persepolis Reimagined** (`Getty × Monks`)
   - **The Pleasure Pursuit** (`Coach × Monks`)
   - **We are all Angel** (`Mugler × Monks`)
   - **BITKRAFT Website** (`BITKRAFT × Monks`)
   - **Year of Greta** (`Superhero Cheesecake`)
   - Deep-dive interactive Case Modal with media showcase, video players, and technical workflow captions.

6. **Working Together & Capabilities**:
   - Complete narrative on Motion Minded™ principles and hands-on prototypes.
   - Joris van Raaij high-resolution portrait.
   - Interactive "COPY EMAIL ADDRESS" pill with live clipboard copy and toast notification.
   - Capability pills and 13-year experience highlight.

7. **Modals & Overlays**:
   - **Showreel Modal**: Full-screen showreel video with custom scrubber timeline and play/pause controls.
   - **Credits Modal**: Special thanks list honoring Mischa Loppies, Sinésio Couceiro, Johan Holwerda, Reinder Nijhoff, Dikkie Baan, and Esmee Lechner.
   - **Sound Studio Modal**: Synthesizer channel controls.
   - **Case Modal**: Dynamic case study deep-dives.

8. **Floating Freelance Pill**:
   - Fixed bottom-right frosted glass pill with animated pulsating emerald glow dot (`#00ff66`).
   - One-click email clipboard copy with toast feedback.

## Running Locally

To run the local server:
```bash
npm start
```
Or with Node.js directly:
```bash
node server.js
```
Open your browser to:
```
http://localhost:8080
```
Or open [index.html](file:///d:/projects/nishanth_portfolio/CLONED%20httpsorchestrated/index.html) directly in any modern web browser.
